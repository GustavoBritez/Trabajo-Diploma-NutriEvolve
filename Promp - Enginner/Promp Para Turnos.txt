Idea General: Implementar el sistema de turnos.

Desarrollo de la idea en lenguaje natural:

Dentro de la GUI tenes que crear un nuevo Form que se denomine "Gestion_Turnos" y agregar un boton dentro de "Form1.cs" ( Este boton es de tipo button y necesita ser llamado como "button_Turnos" porlotanto su evento click correspondiente debe llamarse "btnTurnos_Click" al hacer click en este boton te debera llevar al nuevo formulario creado "Gestion_Turnos"  (Es importante que se integre correctamente la visibilidad de este nuevo formulario dentro de FormManager.cs de lo contrario tendra problemas de compatibilidad)

Tablas

*Tutores_DNI101*
	- IdTutor_DNI101 INT IDENTITY(1,1) PRIMARY KEY
	- DniTutor_DNI101 VARCHAR(20) NOT NULL UNIQUE
	- Nombre_DNI101 VARCHAR(50) NOT NULL
	- Apellido_DNI101 VARCHAR(50) NOT NULL
	- Telefono_DNI101 VARCHAR(50) NOT NULL
	- Email_DNI101 VARCHAR(100) NULL
	- Parentesco_DNI101 VARCHAR(50) NOT NULL
	- FechaRegistro_DNI101 DATETIME2(7) NOT NULL DEFAULT GETDATE()

*Pacientes_DNI101*
	- IdPaciente_DNI101 INT IDENTITY(1,1) PRIMARY KEY
	- DniNiño_DNI101 VARCHAR(20) NOT NULL UNIQUE
	- Nombre_DNI101 VARCHAR(50) NOT NULL
	- Apellido_DNI101 VARCHAR(50) NOT NULL
	- FechaNacimiento_DNI101 DATETIME2(7) NOT NULL
	- Sexo_DNI101 VARCHAR(10) NOT NULL
	- ObraSocial_DNI101 VARCHAR(100) NULL
	- IdTutor_DNI101 INT NOT NULL FOREIGN KEY REFERENCES [dbo].[Tutores_DNI101 ([IdTutor_DNI101])

*AgendasMedicas_DNI101*
	- IdAgenda_DNI101 INT IDENTITY(1,1) PRIMARY KEY
	- Fecha_DNI101 DATE NOT NULL
	- EstadoAgenda_DNI101 VARCHAR(50) NOT NULL (ej: 'Abierta', 'Cerrada')
	- DniNutricionista_DNI101 INT NOT NULL FOREIGN KEY REFERENCES [dbo].[Usuarios]([DNI])

*BloquesHorarios_DNI101*
	- IdBloque_DNI101 INT IDENTITY(1,1) PRIMARY KEY
	- IdAgenda_DNI101 INT NOT NULL FOREIGN KEY REFERENCES [dbo].[AgendasMedicas_DNI101]-([IdAgenda_DNI101])
	- HoraInicio_DNI101 TIME(7) NOT NULL
	- HoraFin_DNI101 TIME(7) NOT NULL
	- EstadoBloque_DNI101 VARCHAR(50) NOT NULL (ej: 'Disponible', 'Ocupado', 'Bloqueado')


*Turnos_DNI101*
	- IdTurno_DNI101 INT IDENTITY(1,1) PRIMARY KEY
	- CodigoTurno_DNI101 VARCHAR(50) NOT NULL UNIQUE
	- FechaTurno_DNI101 DATETIME2(7) NOT NULL
	- HoraTurno_DNI101 TIME(7) NOT NULL
	- MotivoConsulta_DNI101 VARCHAR(255) NOT NULL
	- EstadoTurno_DNI101 VARCHAR(50) NOT NULL (ej.: 'Solicitado', 'Confirmado', 'Asistio', 'Cancelado')
	- IdPaciente_DNI101 INT NOT NULL FOREIGN KEY REFERENCES [dbo].[Pacientes_DNI101]([IdPaciente_DNI101])
	- DniNutricionista_DNI101 INT NOT NULL FOREIGN KEY REFERENCES [dbo].[Usuarios]([DNI]) 
	- IdBloque_DNI101 INT NOT NULL FOREIGN KEY REFERENCES [dbo].[BloquesHorarios_DNI101]([IdBloque_DNI101])

	- TurnoSolicitadoState_DNI101
Implementa IEstadoTurno_DNI101. Permite confirmar el turno (pasa a TurnoConfirmadoState_DNI101), reprogramar o cancelar.

	- TurnoConfirmadoState_DNI101
Estado final. Lanza excepción si se intenta modificar o cancelar un turno finalizado.

	- TurnoAsistioState_DNI101
Estado final. Lanza excepción si se intenta modificar o cancelar un turno finalizado.

	- TurnoCanceladoState_DNI101
Estado final. Libera el bloque horario en AgendaMedicaDAL_DNI101.

	- PacienteBLL_DNI101

-int RegistrarTutor(TutorBE_DNI101 tutor):

Parámetros: tutor (TutorBE_DNI101 con DniTutor_DNI101, Nombre_DNI101, Apellido_DNI101, Telefono_DNI101, Email_DNI101, Parentesco_DNI101).
Retorno: int (ID asignado IdTutor_DNI101).
Reglas de Negocio: Valida que los campos requeridos no estén vacíos. Consulta TutorDAL_DNI101.ObtenerPorDNI(tutor.DniTutor_DNI101); si ya existe, lanza InvalidOperationException("El Tutor ya se encuentra registrado"). De lo contrario, llama a TutorDAL_DNI101.Guardar(tutor) y registra el evento en BitacoraBLL.

-bool ModificarTutor(TutorBE_DNI101 tutor):

Retorno: bool (Éxito o fallo).
Reglas de Negocio: Valida tutor.IdTutor_DNI101 > 0 y ejecuta TutorDAL_DNI101.Modificar(tutor).

-TutorBE_DNI101? ObtenerTutorPorDNI(string dniTutor):

Retorno: TutorBE_DNI101 o null.
Reglas de Negocio: Llama a TutorDAL_DNI101.ObtenerPorDNI(dniTutor). Si existe, recupera también la lista de sus pacientes asociados.

-List<TutorBE_DNI101> ListarTutores():

Retorno: List<TutorBE_DNI101>.
Reglas de Negocio: Devuelve todos los tutores dados de alta.

-int RegistrarPaciente(PacienteBE_DNI101 paciente):

Retorno: int (ID asignado IdPaciente_DNI101).
Reglas de Negocio: Valida paciente.IdTutor_DNI101 > 0. Verifica que la edad (paciente.ObtenerEdadMeses()) sea menor a 228 meses (19 años). Verifica PacienteDAL_DNI101.ObtenerPorDNI(paciente.DniNiño_DNI101); si existe, interrumpe con error. Ejecuta PacienteDAL_DNI101.Guardar(paciente).

- bool ModificarPaciente(PacienteBE_DNI101 paciente):
Parámetros: paciente (PacienteBE_DNI101).
Retorno: bool.
Reglas de Negocio: Actualiza la información del paciente en PacienteDAL_DNI101.Modificar(paciente).

- PacienteBE_DNI101? ObtenerPacientePorDNI(string dniNiño):
Parámetros: dniNiño (string).
Retorno: PacienteBE_DNI101 o null.
Reglas de Negocio: Devuelve el objeto completo del niño con su TutorBE_DNI101 enlazado.

- List<PacienteBE_DNI101> ListarPacientes():
Parámetros: Ninguno.
Retorno: List<PacienteBE_DNI101>.
Reglas de Negocio: Retorna todos los pacientes pediátricos registrados.

- List<PacienteBE_DNI101> ListarPacientesPorTutor(int idTutor):
Parámetros: idTutor (int).
Retorno: List<PacienteBE_DNI101>.
Reglas de Negocio: Llama a PacienteDAL_DNI101.ListarPorTutor(idTutor).
